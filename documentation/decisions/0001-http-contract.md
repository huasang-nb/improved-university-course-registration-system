- 适用范围：HTTP 服务、浏览器页面、会话与 CSRF、教师/管理员接口

## 为什么要有这份文件

团队总手册把 HTTP 方案写成"建议"，我的操作手册要求"先取得 Yuhua 提供的公共状态、会话检查和业务锁"。两份文档里的推荐值如果不落成签字确认项，联调时就会出现"我记得当时说的是另一个值"。本文件把每一处建议变成一行可勾选的确认项：确认人填名字和日期，反对的人必须同时给出可运行的替代方案。

## 确认规则

1. 每条只需回复"同意"，或"反对 + 替代方案 + 原因"。
2. **默认生效**：自本文件提交到群里起 48 小时无异议的条目，按"建议值"执行并记入本节；有异议的条目单独开会 20 分钟裁决。
3. 已确认的值改动时，必须新开一节说明谁提出、为什么改、影响哪些已合并代码。
4. 本文件只写"共同契约"，不写实现细节；实现细节留在各自分支的 README 与代码注释里。

## 三、请求与响应格式

| # | 事项 | 建议值 | 确认后影响 | 确认 |
|---|---|---|---|---|
| 9 | 字段命名 | JSON 一律 snake_case；`role` 取值 `Student`/`Teacher`/`Administrator`；选课状态 `active`/`dropped` | 页面按同一份约定解析 | ☐ |
| 10 | 响应外壳 | `{"code": "...", "message": "...", "data": ...}`；成功空列表 `data: []`；失败 `data: null` | 错误处理只需读 `code` 与 `message` | ☐ |
| 11 | 错误码来源 | 业务错误沿用 `ResultCode` 名称；HTTP 层新增 `AuthenticationRequired`、`CsrfRejected` | 前后端共用一份词表 | ☐ |
| 12 | 状态码映射 | 200 成功；400 `InvalidInput`；401 无会话/停用/凭据错误；403 角色或归属不符、CSRF 失败；404 记录不存在；409 `AlreadyEnrolled`/`TimeConflict`/`TeachingClassFull`/`CapacityBelowEnrollment`/`CatalogInUse`/`DuplicateIdentifier`/`CreditLimitExceeded`/`RegistrationClosed`；500 `Storage*` | 验收时"越权必须是 403、保存失败必须是 500"可直接断言 | ☐ |
| 13 | 入参校验 | 编号只接受正整数并检查 int 范围；拒绝小数/布尔/字符串编号；URL 编号与正文编号必须一致；未知写入字段返回 400；请求体上限 64 KiB | 页面传错时得到明确 400 而不是 500 | ☐ |
| 14 | 时间与时段 | `YYYY-MM-DDTHH:MM` 按服务器时区解释；`day_of_week` 1–7，分钟数 0–1440 | 时间冲突检查与学生端一致 | ☐ |

## 四、会话与 CSRF

| # | 事项 | 建议值 | 确认后影响 | 确认 |
|---|---|---|---|---|
| 15 | 会话载体 | 随机 32 字节会话编号放 Cookie `team4_session`；`Path=/`、`HttpOnly`、`SameSite=Lax`，HTTPS 下加 `Secure` | 前端不需要自己保存 token | ☐ |
| 16 | 会话时长 | 空闲 30 分钟、最长 8 小时（**已确认**）。空闲时间从最近一次通过身份验证的 API 请求开始计算，页面/图片等静态资源请求不延长会话；最长 8 小时从登录成功开始计算，后续请求不延长。退出登录、账号停用或改号后，旧身份被拒绝 | 演示时"放置多久要重新登录"按此口径 | ☑ 2026-11-28 |
| 17 | 登录/退出 | 登录成功换发新编号；退出删除服务端会话并清 Cookie；服务重启后全部会话失效 | 旧编号不能再用 | ☐ |
| 18 | 会话有效性 | 每次请求都要重查当前人员记录；账号被停用、账号名被改 → 旧会话立即拒绝（401） | 停用账号能真正断开访问 | ☐ |
| 19 | CSRF | 写操作（POST/PUT/PATCH/DELETE）必须带 `X-CSRF-Token`；值来自 `GET /api/auth/me`；缺失或不属于当前会话 → 403 `CsrfRejected` | 防止页面被第三方站点代提交 | ☐ |
| 20 | 响应字段裁剪 | 人员响应不含 `password_hash`；不返回会话编号、服务器路径、内部异常堆栈 | 防止截图与日志泄露凭据 | ☐ |
